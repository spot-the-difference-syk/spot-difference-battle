# 게임 기획

> 문서 상태: CURRENT
> 기준일: 2026-10-02
> 규칙과 수치는 `GAME_RULES.md`를 따른다.

## 한 줄 설명

"틀린그림 갤러리" — 실사·애니·회화·카툰·게임 등 다양한 화풍의 그림을 전시관처럼 둘러보며, 같은 그림 두 장에서 다른 곳을 찾는 게임이다. 1대1 실시간 대결과 혼자하기(솔로 타임어택)가 있고, 레벨·코인·꾸미기·수집으로 계속 돌아올 이유를 만든다.

## 핵심 재미

- 관찰력과 반응 속도를 직접 겨룬다.
- 그림을 끝낼 때마다 흐름이 끊기지 않고 다음 그림으로 넘어간다.
- 상대의 진행도를 보며 추격하거나 격차를 벌린다.
- 끝까지 푼 그림이 "내 갤러리"에 쌓이고, 레벨과 꾸미기로 내 전시 스타일을 만든다.

## 핵심 루프

`홈(오늘의 전시) → 대결 또는 혼자하기 → 그림 풀기 → 결과·보상(경험치·코인·수집) → 꾸미기·내 갤러리 → 다시 도전`

대결은 두 사람이 같은 순서의 그림 10점을 각자 진행한다. 그림별 선착 보너스는 없으며, 빨리 끝내 다음 그림을 먼저 시작하는 것이 보상이다.

## 디자인 방향

- 갤러리 콘셉트: 종이색 로비와 어두운 전시 무대, 먹색과 금색 포인트. 어떤 화풍의 그림도 어울리도록 중립적으로 만든다.
- 한국어만 쓰고 해요체로 안내한다.
- 원본과 수정본은 항상 같은 크기로 보여준다. 세로 화면은 위아래, 가로·태블릿·PC는 좌우 배치다.
- 찾은 곳은 뷰파인더 표시로, 상대 위치는 숨긴다.
- 웹·앱인토스·Android(WebView)에서 같은 화면을 쓴다.

## 콘텐츠 원칙

- 대결 그림은 차이 정확히 3개, 솔로 그림은 5개다.
- 차이는 색상만으로 구분하지 않고 형태·존재·상태 변화를 섞는다.
- 정답 영역 밖의 생성형 미세 변화는 정답으로 쓰지 않는다.
- 같은 경기 안에서는 그림을 반복하지 않는다.
- 그림은 R2에 올리고 그림 목록(DB)에 등록하면 재배포 없이 추가된다(`GAME_ASSETS.md`).

## 상품화 요소

- 레벨·경험치·코인: 서버가 계산한다. 코인은 천천히 모이도록 아이템 가격을 500~3,000으로 잡았다.
- 꾸미기: 정답 표시·액자·프로필 테두리·칭호.
- 수집·전적·오늘의 목표.
- 다음 단계: 토스 로그인으로 기록을 계정에 연결하고, 유료 결제를 검토한다(`IMPLEMENTATION_BACKLOG.md`).

## 성공 지표

- 경기 완주율과 평균 완료 그림 수
- 그림별 평균 풀이 시간과 오답률
- 첫 경기 후 재도전 비율, 일간 재방문(오늘의 목표 달성률)
- 모바일·데스크톱 간 정답률 차이
- 이미지 로드 실패율과 재접속 성공률
- 그림 신고율

## 아직 하지 않는 것

시즌, 유료 결제, 사용자 이미지 업로드, 채팅, 관전, 리플레이, 재대전, 그림별 선착 보너스는 후속 검토한다.
