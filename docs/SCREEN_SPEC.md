# 화면 명세

> 문서 상태: CURRENT
> 기준일: 2026-10-01
> 게임 동작은 `GAME_RULES.md`, 구현 기준은 `design/UI_GUIDELINES.md`를 따른다.

## 공통 원칙

- 원본과 수정본("여기서 찾기")을 명확하게 표기하고 항상 같은 크기로 보여준다.
- 정답·오답·잠금은 색상뿐 아니라 문구와 형태로 알린다.
- 터치 대상은 모바일 최소 크기를 확보한다.
- 확대·이동 동작과 정답 선택을 구분한다.
- 남은 시간과 진행은 항상 확인 가능해야 한다.
- 화면 문구는 한국어 해요체만 쓴다.

## 앱 틀

- 메뉴: 홈 · 혼자 하기 · 꾸미기 · 내 정보. PC는 상단, 폰·태블릿은 하단 탭 막대.
- 머리글: 서비스 이름 "틀린그림 갤러리", 프로필(레벨 링·테두리)과 코인.
- 처음 접속: 닉네임 정하기("처음 오셨네요").

## 홈

- 오늘의 전시(날짜마다 바뀌는 대표작)와 안내 문구 "같은 그림 속 다른 한 곳을 찾아보세요"
- 모드(기본전·속도전·생존전)와 난이도(쉬움·보통·어려움) 선택, 대결하기
- 오늘의 목표 진행
- 전시 중인 그림: 화풍 탭(전체·실사·애니·회화·카툰·게임)과 썸네일 목록

## 매칭과 준비

- 상대 찾는 중 + 매칭 취소
- 상대를 찾았어요: 상대 닉네임·프로필 테두리·칭호, 시작하기(준비)
- 그림 준비 중(이미지 로드), 곧 시작해요(3초 카운트다운). 카운트다운 전에는 그림을 가린다.

## 경기 화면

- 원본·수정본 보드(같은 크기, 세로 화면은 위아래·가로 화면은 좌우)
- 남은 시간, 그림 10점 진행 막대, 나와 상대의 진행
- 찾은 곳 뷰파인더 표시, 오답·입력 잠금 안내, 정답 토스트
- 확대(1~3배)·이동 컨트롤. 원본·수정본에 같은 배율과 이동을 적용하고 드래그는 정답 선택으로 처리하지 않는다.
- 현재 그림을 흐리게 깐 어두운 무대 배경
- 나가기(기권)

## 결과 화면

- 승리·패배·무승부·취소와 종료 사유
- 양쪽 완료 상태, 발견 수, 총점, 오답 수
- 보상: 경험치·코인, 레벨업, 새로 수집한 그림, 오늘의 목표 달성 보너스
- 로비로 돌아가기, 그림 신고(불공정한 문제·이미지 문제·부적절한 표현·시스템 오류·기타)

## 혼자 하기

- 그림 카드 목록(최고 기록 표시) → 시작
- 경기 화면과 같은 보드, 발견 수·오답 표시, 그만하기
- 완료: 기록·개인 최고기록 여부·보상, 다시 도전·다른 문제·홈으로

## 꾸미기

- 자리별(정답 표시·액자·프로필 테두리·칭호) 아이템 목록, 미리보기
- 잠김(해금 레벨)·구매(코인)·사용하기·사용 중 상태

## 내 정보

- 레벨·경험치·코인, 전적(승·무·패·승률·솔로 완주), 오늘의 목표
- 내 갤러리: 수집한 그림과 수집 수

## 접근성·오류

- 키보드 포커스와 스크린리더 이름, 아이콘 버튼 `aria-label`
- 입력 잠금 상태 안내
- 이미지 로드 실패 시 다시 시도
- 재접속 중 안내("서버와 다시 연결하고 있어요"), 상대 연결 끊김 10초 대기 안내
- 서버에 연결되지 않으면 꾸미기·내 정보 대신 연결 안내

## 남은 보완점

- 결과에서 그림별 전체 정답을 넘겨보는 화면
- 재접속 남은 시간 숫자 표시
- 그림 전환 애니메이션
- Firefox·WebKit 반복 검증, 색각·저사양 모바일 점검
