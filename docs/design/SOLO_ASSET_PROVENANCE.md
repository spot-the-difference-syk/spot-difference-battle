솔로 타임어택의 원본·변경본 5쌍은 OpenAI ImageGen으로 신규 생성했다. 경쟁전 이미지는 재사용하지 않았다. 모든 배포 파일은 1024×1024 WebP이며 파일명, 버전과 SHA-256은 `apps/web/src/features/solo/puzzles/manifest.ts`에서 관리한다.

## 원본 프롬프트 방향

공통 프롬프트는 작은 물건이 많지만 서로 구분되는 정사각형 장면, 선명한 동화풍 디지털 일러스트, 글자·숫자·상표·워터마크·인물 없음으로 지정했다.

| ID | 장면 | 주요 구성 |
|---|---|---|
| `observatory` | 달빛 천문대 | 황동 망원경, 천체도, 책장, 천구의, 모래시계 |
| `bakery` | 아침의 베이커리 | 빵, 조리도구, 구리팬, 그릇, 잼, 오븐 |
| `greenhouse` | 비밀의 온실 | 식물, 나비, 화분, 원예도구, 분수, 의자 |
| `alpine-station` | 알프스 산악역 | 산악열차, 시계, 우산, 고양이, 여행가방, 꽃 |
| `clockmaker` | 시계공의 작업실 | 여러 시계, 기어, 기계 새, 모래시계, 안경, 열쇠 |

## 변경본 프롬프트 방향

각 원본을 편집 대상으로 사용해 카메라·구도·조명·나머지 물체를 유지하고 아래 다섯 위치만 바꾸도록 지정했다.

| ID | 의도한 다섯 차이 |
|---|---|
| `observatory` | 책장 화분 제거, 보름달→초승달, 모래 색, 망원경 리본 추가, 돋보기 제거 |
| `bakery` | 시계 바늘, 거품기 제거, 그릇 색, 잼 덮개 색, 크루아상 제거 |
| `greenhouse` | 나비 색, 파란 병 제거, 장갑 색, 다육식물 제거, 물뿌리개 색 |
| `alpine-station` | 시계 바늘, 우산 색, 고양이 목걸이 추가, 모자 제거, 꽃바구니 색 |
| `clockmaker` | 기계 새 색, 시계 바늘, 모래 색, 안경알 제거, 열쇠 제거 |

생성형 편집에서 생길 수 있는 영역 밖의 미세 픽셀 변화는 정답이 아니다. 카탈로그에 수동 등록된 다섯 영역만 정답으로 판정한다. 출시 전 실제 모바일 화면에서 식별 가능성과 의도하지 않은 시각 차이를 최종 검수한다.

## 2026-10-01 수정

- `bakery` 변경본: 벽시계 바늘이 원본과 같아 찾을 수 없던 문제를 수정했다. 변경본 시계 바늘을 4시 35분 방향으로 다시 그렸다(버전 `2026-10-01.1`).
- `greenhouse` 변경본: 정답으로 등록되지 않은 차이(모종삽 옆 두 번째 장갑 제거)를 원본으로 되돌려, 장갑 차이가 하나만 남도록 했다(버전 `2026-10-01.1`).
- 정답 판정: `alpine-station` 시계는 문자판 전체를 정답으로 바꿔 두 바늘 모두 인정한다. 크기가 큰 변경(돋보기, 물뿌리개, 우산, 꽃바구니, 모래시계)은 `extraRegions`로 물체 전체를 정답 범위에 포함했다.
