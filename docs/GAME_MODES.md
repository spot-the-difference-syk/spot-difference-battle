# 게임 모드와 난이도

> 문서 상태: CURRENT
> 기준일: 2026-10-01
> 승패와 수치의 정본은 `GAME_RULES.md`다.

모든 모드는 같은 순서의 그림 10점에서 그림마다 차이 3개를 찾는 기본 규칙을 공유한다. 서버는 같은 모드와 난이도를 선택한 플레이어끼리만 매칭한다.

## 게임 모드

| 모드 | 제한시간 | 추가 규칙 |
| --- | ---: | --- |
| 기본전 | 180초 | 기본 규칙 그대로 진행한다. |
| 속도전 | 60초 | 기본전과 같은 승패 기준을 짧게 진행한다. |
| 생존전 | 120초 | 누적 오답 3회에 먼저 도달하면 즉시 패배한다. |

## 난이도

난이도는 이미지를 바꾸지 않고 클릭 판정 범위와 오답 잠금만 조절한다. 따라서 두 플레이어는 반드시 같은 난이도로 경기한다.

| 난이도 | 정답 판정 반경 | 오답 잠금 |
| --- | ---: | ---: |
| 쉬움 | 기준의 125% | 0.5초 |
| 보통 | 기준의 100% | 1초 |
| 어려움 | 기준의 80% | 2초 |

## 재미 피드백

정답을 연속으로 찾으면 콤보가 증가하고 2연속부터 화면에 표시한다. 오답이면 현재 콤보는 0으로 초기화되며 최고 콤보는 경기 복구 데이터에 유지된다. 콤보는 현재 승패 점수에는 영향을 주지 않는다.

## 공통 승패 기준

그림 10점을 먼저 모두 끝낸 플레이어가 즉시 이긴다. 시간이 끝나면 다음 순서로 판정한다.

1. 총점(찾은 차이 1개당 10점 + 모두 끝냈다면 남은 시간 1초당 0.5점)이 높은 플레이어
2. 오답이 적은 플레이어
3. 전체를 먼저 끝낸 플레이어
4. 모두 같으면 무승부

생존전의 오답 3회 패배와 기권은 위 비교보다 먼저 적용된다. 모드, 난이도, 제한시간, 판정과 종료는 서버가 최종 결정한다.
