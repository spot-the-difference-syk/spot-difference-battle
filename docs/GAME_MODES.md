# 게임 모드

> 문서 상태: CURRENT
> 기준일: 2026-10-02
> 승패와 수치의 정본은 `GAME_RULES.md`다.

모든 모드는 같은 순서의 그림(한 화풍, 최대 10점)에서 그림마다 차이 3개를 찾는 기본 규칙을 공유한다. 서버는 같은 모드를 선택한 플레이어끼리만 매칭한다.

## 게임 모드

| 모드 | 제한시간 | 추가 규칙 |
| --- | ---: | --- |
| 기본전 | 180초 | 기본 규칙 그대로 진행한다. |
| 속도전 | 60초 | 기본전과 같은 승패 기준을 짧게 진행한다. |
| 생존전 | 120초 | 누적 오답 3회에 먼저 도달하면 즉시 패배한다. |

## 판정과 오답 잠금

난이도 선택은 없다(2026-10-02). 정답 판정 반경은 그림에 등록된 반경 그대로이고, 오답이면 1초 동안 입력이 잠긴다(`GAME_CONFIG.wrongAnswerLockSeconds`).

## 그림 화풍

서버는 경기마다 화풍(실사·애니·회화·카툰·게임) 하나를 무작위로 정하고, 그 화풍의 활성 대결 그림 중 최대 10점을 무작위로 뽑아 두 플레이어에게 같은 순서로 제공한다(`GAME_CONFIG.puzzlesPerMatch`). 플레이어는 화풍을 고르지 않는다. 그림이 3점(`minPuzzlesPerGenre`) 미만인 화풍은 고르지 않으며, 그런 화풍만 있으면 전체에서 섞는다. 따라서 한 경기의 그림 수는 화풍에 따라 3~10점이다.

## 재미 피드백

정답을 연속으로 찾으면 콤보가 증가하고 2연속부터 화면에 표시한다. 오답이면 현재 콤보는 0으로 초기화되며 최고 콤보는 경기 복구 데이터에 유지된다. 콤보는 현재 승패 점수에는 영향을 주지 않는다.

## 공통 승패 기준

이번 경기 그림을 먼저 모두 끝낸 플레이어가 즉시 이긴다. 시간이 끝나면 다음 순서로 판정한다.

1. 총점(찾은 차이 1개당 10점 + 모두 끝냈다면 남은 시간 1초당 0.5점)이 높은 플레이어
2. 오답이 적은 플레이어
3. 전체를 먼저 끝낸 플레이어
4. 모두 같으면 무승부

생존전의 오답 3회 패배와 기권은 위 비교보다 먼저 적용된다. 모드, 화풍·그림 순서, 제한시간, 판정과 종료는 서버가 최종 결정한다.
