# 상품화와 결제 계획

> 문서 상태: PROPOSED
> 기준일: 2026-10-02
> 아이템과 가격의 정본은 `packages/shared/src/game/cosmetics.ts`의 `COSMETIC_ITEMS`, 규칙은 `GAME_RULES.md` 12절이다.

## 지금(구현됨)

- **명작 컬렉션**: 움직이는 고급 꾸미기 30종(`premium: true`). 레벨 제한 없이 코인으로 산다(5,000~16,000코인).
  - 정답 표시: 반짝이 가루, 나비, 불꽃놀이, 물결 파문, 하트 뿅뿅, 마법진
  - 액자: 벚꽃 액자, 별밤 액자, 명작 금장, 레이스, 비취, 우주
  - 프로필 그림: 해바라기, 벚꽃 고양이, 연못의 비단잉어, 큰 파도, 별이 빛나는 밤, 은하 고래, 어항 금붕어, 등불 토끼, 스노볼, 반딧불 숲, 구름 위 성, 오로라 여우
  - 테두리: 별 궤도, 불꽃, 은하수, 꽃잎 화관, 프리즘, 번개
- 꾸미기 화면에서 기본 아이템 다음, 일반 아이템 앞에 "명작" 표시와 함께 보인다.
- 코인은 게임으로만 번다(하루 약 600~800코인). 그래서 명작 아이템 하나는 1~3주 정도 모아야 살 수 있다. 이 차이가 나중에 코인 묶음을 팔 이유가 된다.

## 나중(현금 결제)

권장 방식은 **코인 묶음 판매**다. 아이템을 직접 팔지 않고 코인을 팔면, 아이템 목록·구매 코드를 그대로 쓰고 가격 실험도 코인 묶음 쪽에서만 하면 된다. 특정 명작 아이템을 바로 사는 상품이 필요하면 `premium` 아이템 ID를 상품 ID에 연결한다.

### 먼저 필요한 것

1. **계정 연동(필수)**: 지금 기록을 찾는 열쇠는 기기의 게스트 토큰이다. 돈을 내고 산 코인·아이템이 앱 삭제나 기기 변경으로 사라지면 안 되므로, 결제보다 토스 로그인 연동(`IMPLEMENTATION_BACKLOG.md`)을 먼저 끝낸다.
2. **결제 수단은 출구마다 다르다**:
   - 앱인토스: 토스 인앱 결제
   - Android(Google Play): Play 결제(디지털 상품은 Play 결제 필수)
   - iOS(App Store): 인앱 구매(디지털 상품은 Apple 인앱 구매 필수)
   - 웹: 별도 PG가 필요하다. 처음에는 웹 결제를 열지 않는 것을 권장한다.
3. **서버 검증**: 결제 영수증(주문 ID)을 게임 서버가 결제사에 직접 확인한 뒤에만 코인을 준다. 클라이언트가 "샀다"고 알리는 값은 믿지 않는다.
4. **중복 지급 방지**: 같은 주문 ID는 한 번만 반영한다(이미 랭킹 보상에 쓰는 "한 번만 지급" 방식과 같다). 결제 기록은 Supabase에 별도 표(예: `purchases`: 주문 ID, 플레이어, 상품, 금액, 상태, 시각)로 남긴다. Supabase 담당과 스키마를 정한다.
5. **환불·취소**: 결제사의 환불 알림을 받아 코인을 회수하거나 표시한다. 이미 쓴 코인 처리 기준을 정한다.
6. **정책 검토**: 전자상거래법(청약 철회 안내), 미성년자 결제, 확률형 아이템은 만들지 않음, 사업자·통신판매업 신고, 약관·개인정보 처리방침.

### 코드에서 바꿀 곳(예상)

- 공유 패키지: 코인 묶음 목록(`COIN_PACKS`: 상품 ID, 코인 수, 표시 가격)과 주문 ID를 한 번만 반영하는 `grantPurchase` 정산 함수
- 게임 서버(Worker): 결제 확인 이벤트 처리, 결제사 검증 호출, `player:growth`로 결과 전달
- 웹: 꾸미기 화면 "코인 충전" 버튼과 출구별 결제 연결, 코인 부족 시 충전 안내
