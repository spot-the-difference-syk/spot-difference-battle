# 2026-08-18 변경 내역

## 메인 브랜치 통합

- 팀원이 제거한 경기 중 문제 제작·제출 API를 현재 멀티 퍼즐 대전 구조에 통합했다.
- 제작·교환·힌트 이벤트와 편집기, 장면 객체 카탈로그, 제출 이미지 검증 코드를 제거했다.
- 기존 모드(기본전·속도전·생존전), 난이도와 콤보 피드백은 유지했다.

## 운영 안정성

- 비활성 게스트 세션 레지스트리와 만료 정리를 추가했다.
- 게스트 마지막 활동 시각을 메모리·PostgreSQL 저장소에서 복원한다.
- 운영 로그는 경기·플레이어·상태·오류 코드만 구조화하고 토큰·이미지·신고 상세를 기록하지 않는다.

## 규칙 정합성

- 공용 상태에서 `EDITING`, `SWAPPING`, `FINDING`을 제거했다.
- 게임 규칙과 README의 고정 3분·1초 표현을 모드·난이도별 수치로 통일했다.
- 게임의 단일 흐름은 `READY → PRELOADING → COUNTDOWN → PLAYING → FINISHED`다.
