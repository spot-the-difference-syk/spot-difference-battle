# 2026-08-08 변경 내역

> 문서 상태: HISTORICAL

> 현재 규칙 정합화와 레드팀·QA 후속 보강 기록이다. 현재 규칙의 정본은 `GAME_RULES.md`다.

## 완료

- 정상 경기를 준비된 문제 완주로 조기 종료하지 않고 제한시간까지 유지하도록 코어·서버·E2E를 통일했다.
- 상대 스냅샷에서 문제 인덱스, 총 발견 수, 오답 수, 입력 잠금 시각을 제거했다.
- 중복 정답을 `DUPLICATE`로 구분하고 상태가 바뀌지 않으면 전체 스냅샷 전송과 DB 저장을 생략한다.
- 문제마다 고유 정답 ID 3개와 단일·유효·비중첩 영역 3개를 강제했다.
- 숲 문제의 버섯 정답을 한 개의 연결된 클릭 영역으로 통일했다.
- 완료 경기 저장이나 활성 경기 삭제가 실패하면 성공으로 표시하지 않고 오류를 전파하도록 보강했다.
- 모바일 확대·드래그와 Chromium·Firefox·WebKit 완료 상태를 CURRENT 문서에 반영했다.

## 검증

- `pnpm check`
- `pnpm test`: 46개 통과, 실제 `DATABASE_URL`이 필요한 PostgreSQL 재시작 1개 조건부 제외
- `pnpm build`
- `pnpm e2e`: Chromium·Firefox·WebKit 6개 통과

## 공개 출시 전 남은 항목

- 문제 쌍 version·SHA-256·난이도·라이선스 메타데이터의 실행 계약과 파일 검증
- 세 번째 이후 문제 로드 실패의 3회/10초 재시도 및 기술적 무효 처리
- 게스트 세션 TTL·생성/재매칭 요청 제한
- 실제 PostgreSQL 재시작 검증
- 실제 iOS 기기 검증과 최소 10개 문제 쌍 확보

## 사용자 플레이 점검 후 긴급 격리

- 숲 변경본의 오른쪽 하단 버섯과 벤치 새가 서버 정답에 등록되지 않은 추가 시각 차이임을 확인했다.
- 정확히 3개 차이 규칙을 임시로 깨거나 오답 판정을 허용하지 않도록 숲 문제를 일반 매칭에서 제외했다.
- 숲 문제 정의와 자산은 수정본 재제작 및 QA를 위해 보존하며, 현재 일반 매칭은 검증된 바다 문제만 사용한다.
