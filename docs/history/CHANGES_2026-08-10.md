# 2026-08-10 변경 내역

> 문서 상태: HISTORICAL

## 같은 Wi-Fi 휴대폰 테스트 지원

- Vite 개발 서버를 LAN 인터페이스에 바인딩
- 개발 웹이 현재 브라우저 호스트의 `3001` 포트로 API 주소를 자동 계산
- 서버 개발 CORS를 `localhost`, `127.0.0.1`, RFC 1918 사설 IPv4의 `5173` 포트로 제한
- 명시적인 `VITE_SERVER_URL`·`WEB_ORIGIN`과 운영 환경의 동일 출처 동작은 유지
- URL 계산과 개발 허용 출처 정책 단위 테스트 추가
- README와 테스트 계획에 실제 휴대폰 접속 절차 추가

이 변경은 같은 사설 Wi-Fi에서의 개발 검수만 지원한다. 공용 인터넷에 개발 서버를 직접 노출하는 배포 설정은 아니다.

## 퍼즐 에셋 단일 매니페스트

- 활성 5세트의 문제 ID·버전·난이도·권리 상태를 공유 패키지로 통합
- 원본·변경본 WebP의 파일명·크기·SHA-256을 한 곳에 기록
- 웹 카탈로그가 공유 메타데이터를 직접 참조하도록 연결
- 서버 문제 목록과 공유 문제 ID가 정확히 일치하는지 자동 검사
- 실제 배포 파일 10개의 해시 일치 및 원본·변경본 분리를 자동 검사

이미지만 덮어써서 기존 정답 영역과 다른 그림이 노출되는 문제를 테스트 단계에서 차단한다. 실제 경기 기록에 사용 버전을 영구 보존하는 감사 데이터는 별도 저장소 마이그레이션 단계로 남긴다.
