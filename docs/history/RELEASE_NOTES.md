# 변경 이력


이 프로젝트의 주요 변경 사항을 기록합니다.


버전 번호는 [Semantic Versioning](https://semver.org/lang/ko/) 형식인 `주버전.기능.수정`을 사용합니다.


과거 버전은 당시 구현을 설명하는 역사 기록이며 규칙 문서가 아닙니다. 현재 게임 규칙의 유일한 Markdown 정본은 `docs/GAME_RULES.md`이고, `docs/MVP_DECISIONS.md`는 결정 근거만 기록합니다.


## [Unreleased]


### 전체 완료 즉시 종료 및 시간 가산점


- 두 플레이어가 경기의 모든 차이점을 찾으면 제한시간을 기다리지 않고 즉시 종료
- 문제별 실제 차이점 수를 사용해 경기 전체 수를 계산하고 결과를 `완료 · 발견 수/실제 전체 수`로 표시
- 정답 1개당 10점과 완주 시 남은 시간 1초당 0.5점의 가산점을 총점에 반영
- 경기 중 상대의 현재 문제 번호와 현재 문제 발견 수·실제 정답 수를 실시간 표시
- 게임 코어, 서버 저장 복구, 웹 UI와 자동 테스트를 새 진행·점수 필드에 맞게 갱신


### 동시 빨리찾기 규칙 전환


- 경기 중 제작자/찾는 사람 역할을 제거하고 두 플레이어가 같은 원본·변경본을 동시에 비교하는 빨리찾기 대결로 전환
- 차이 3개를 모두 찾으면 각자 즉시 다음 문제로 이동하고 3분 동안 완료 문제 수·현재 발견 수·오답 순서로 승패 판정
- 검증된 원본·변경본·정답 3곳으로 구성된 문제 쌍 카탈로그 도입
- 문제 사전 로드, 3초 카운트다운, 오답 1초 입력 잠금과 경쟁전 힌트 제거
- 공유 상태·게임 코어·서버·웹·자동 테스트를 전환하고 새 규칙 문서를 `CURRENT`로 승격


### 추가


- 서버가 선택한 장면 ID와 웹 이미지·객체 마스크를 연결하는 다중 장면 카탈로그 기반
- 사용자 제공 카툰 연구실 후보 장면과 18개 객체 마스크
- 사용자 제작 카페·마법 숲·사이버 도시·바닷속 보물 장면과 장면별 15개 객체 마스크
- 새 장면 4개의 서버용 1024×1024 PNG와 웹용 무손실 WebP
- 장면 ID별 서버 원본 이미지 카탈로그와 제출 이미지 좌표 검증
- 등록되지 않은 객체·중복 객체·허용되지 않은 효과의 서버 제출 차단
- 제작부터 풀이까지 혼자 확인할 수 있는 1인 테스트 모드
- 고양이·화분·공·창문·구름·베개·소파·전등 등 16개 수동 객체 마스크
- 객체별 색상 변경, 가로 확대, 세로 확대, 줄무늬, 점무늬, 별 무늬, 윤곽 효과
- 제작자와 찾는 사람을 분리한 비대칭 온라인 경기 흐름
- 제작 중 찾는 사람에게 편집 그림과 정답 정보를 숨기는 비공개 대기 화면


- PostgreSQL 기반 경기 결과 및 플레이어별 진행 기록 저장
- 서버 재시작 후 게스트 세션과 진행 중 경기 상태 복구
- 실제 PostgreSQL을 사용하는 서버 재시작 복구 통합 테스트
- 종료되거나 취소된 경기의 문제 신고 접수
- 서버 오류로 취소된 경기의 사유 표시 및 전적 제외 처리
- 로컬 개발용 PostgreSQL Docker Compose 구성과 데이터베이스 마이그레이션 명령
- React·Fastify·Socket.IO를 단일 운영 컨테이너로 구성
