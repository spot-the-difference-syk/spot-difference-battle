# 2026-08-03 변경 내역

> 문서 상태: HISTORICAL

## 컨테이너 배포 기반 준비

- 프로덕션 웹이 별도 서버 주소 없이 현재 도메인의 Socket.IO에 연결하도록 변경했다.
- Fastify가 빌드된 React 정적 파일과 `/health`를 같은 서비스에서 제공할 수 있게 했다.
- Node.js·pnpm 기반 다단계 `Dockerfile`과 최소 빌드 컨텍스트용 `.dockerignore`를 추가했다.
- 단일 컨테이너 웹 서비스의 테스트 배포를 위한 설정과 PostgreSQL 연결 환경 변수를 준비했다.
- `DATABASE_URL`이 있으면 컨테이너 시작 전에 기존 마이그레이션을 적용한다.
- 정적 웹과 상태 확인 경로가 함께 동작하는 서버 통합 테스트를 추가했다.
- 배포·환경 변수·모바일 확인·되돌리기 절차를 `DEPLOYMENT.md`에 정리했다.

## 검증

- `pnpm check` 통과
- `pnpm test` 47개 통과, 실제 PostgreSQL 전용 1개 건너뜀
- `pnpm build` 통과
- Chromium·Firefox·WebKit E2E 12개 통과
- 최소 배포 산출물에서 `/`, `/health`, Socket.IO 핸드셰이크 통과
- 로컬 Docker CLI는 있으나 Docker Desktop 엔진이 꺼져 있어 이미지 자체 빌드는 실행하지 못함
