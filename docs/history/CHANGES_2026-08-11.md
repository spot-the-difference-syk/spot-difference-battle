# 2026-08-11 변경 내역

> 문서 상태: HISTORICAL

## 퍼즐 버전 일치와 종료 경기 감사 저장

- 서버 문제 카탈로그의 각 문제에 공유 매니페스트 버전을 연결
- 경기 스냅샷에 현재·다음 문제 버전을 포함
- 클라이언트의 첫 문제 로드 승인에 문제 버전을 포함하고 서버 값과 다르면 경기 시작 전 거부
- 버전이 없는 구형 활성 경기는 복구 과정에서 해당 경기만 격리
- PostgreSQL `matches.puzzle_manifest`에 경기의 문제 순서·버전·정답 영역을 JSON으로 보존
- 종료 결과 저장이 공개용 상대 스냅샷 대신 서버 내부 상태의 발견 수·오답 수를 사용하도록 수정
- 잘못된 문제 버전 거부, 스냅샷 버전과 감사 데이터 보존 테스트 추가

구형 제작·편집 호환 타입과 비활성 모듈은 현재 경기 실행 경로에서 사용하지 않는다. 저장 데이터와 이전 클라이언트 호환을 깨뜨리는 일괄 삭제는 별도 마이그레이션과 지원 종료 결정을 거쳐 진행한다.
