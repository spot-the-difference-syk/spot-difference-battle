# 2026-08-09 변경 내역

> 문서 상태: HISTORICAL

> 사용자가 제공한 원본·변경본 5쌍을 검증하고 활성 문제로 등록한 기록이다.

## 등록한 문제

| 문제 | 원본 → 변경본 | 정답 3곳 |
|---|---|---|
| 햇살 좋은 카페 | 이미지 2 → 이미지 1 | 시계 바늘, 꽃, 고양이 |
| 마법의 버섯 숲 | 이미지 7 → 이미지 3 | 등불, 토끼 목도리, 지붕 새 |
| 바닷속 보물 | 이미지 8 → 이미지 4 | 거북이 모자, 해파리 색, 보물상자 |
| 네온 사이버 도시 | 이미지 5 → 이미지 6 | 대형 네온, 비행 자동차, 헤드폰 색 |
| 눈 내린 겨울 산장 | 이미지 9 → 이미지 10 | 굴뚝 연기, 눈사람 모자, 모닥불 색 |

제공 원본은 모두 1024×1024 JPG이며 문제당 고유 정답 ID와 단일·비중첩 클릭 영역을 정확히 3개 등록했다. 기존에 추가 차이가 있어 격리했던 숲 파일은 사용하지 않고 새 쌍으로 교체했다.

## 적용 범위

- 공유 문제 ID 5개 등록
- 서버 문제 순서와 정답 좌표 등록
- 웹 원본·변경본 자산 카탈로그 교체
- 서버·브라우저 테스트를 무작위 5문제 순서에 맞게 확장
- 에셋·권리·백로그·테스트 문서 갱신

## 후속 품질 개선

- 배포 이미지를 1024×1024 WebP 품질 88로 변환
- 퍼즐 이미지 총용량을 10,032,236바이트에서 2,654,722바이트로 73.5% 절감
- 같은 퍼즐의 중복 요청·디코딩을 막는 선로딩 Promise 캐시 추가
- 로비와 결과 화면에 실제 서버 승부 기준 명시
- 남은 시간 30초는 주황색, 10초는 점멸 빨간색으로 강조

## 남은 검증

- 실제 PC·모바일에서 정답 원의 크기와 난이도 조정
- 문제 version·SHA-256 메타데이터의 런타임 검증 계약
- 3분 경기용 최소 10세트 확보
