# 게임 상태

> 문서 상태: CURRENT
> 기준일: 2026-08-22
> 승패와 수치는 `GAME_RULES.md`를 따른다.

## 1. 상태

| 상태 | 의미 | 종료 조건 |
|---|---|---|
| `LOBBY` | 닉네임 설정과 대전 진입 | 매칭 요청 |
| `MATCHING` | 상대 검색 | 두 명 매칭 또는 취소 |
| `READY` | 양쪽 참가와 준비 확인 | 양쪽 준비 완료 또는 30초 시간초과 |
| `PRELOADING` | 문제 순서·버전 확정과 이미지 사전 로드 | 양쪽이 같은 첫 문제 버전 로드 완료 또는 실패 |
| `COUNTDOWN` | 문제를 가린 3초 시작 대기 | 서버 시작 시각 도달 |
| `PLAYING` | 양쪽이 독립적으로 차이를 찾고 다음 문제로 이동 | 한 명의 전체 문제 완료, 제한시간, 기권 또는 기술적 오류 |
| `FINISHED` | 최종 점수와 승패 공개 | 로비 이동 |

정상 흐름은 `LOBBY → MATCHING → READY → PRELOADING → COUNTDOWN → PLAYING → FINISHED`다. 제작·교환 단계는 상태와 실행 경로에서 제거됐다.

## 2. 입력 권한

| 상태 | 허용 입력 |
|---|---|
| `LOBBY` | 닉네임 저장, 매칭 시작 |
| `MATCHING` | 매칭 취소 |
| `READY` | 준비, 나가기 |
| `PRELOADING` | 이미지 로드 완료·실패, 나가기 |
| `COUNTDOWN` | 나가기 |
| `PLAYING` | 위치 선택, 나가기 |
| `FINISHED` | 로비 이동, 신고 |

두 플레이어의 권한은 같다. 제작 제출, 편집, 자동 보충과 경쟁전 힌트 입력은 제거한다.

## 3. 플레이어별 진행

- 현재 문제 인덱스와 `pairId`·에셋 버전
- 현재 문제에서 발견한 정답 ID
- 완료 문제 수, 현재 문제의 실제 정답 수, 총 발견 수와 경기 전체 실제 정답 수
- 전체 완료 여부, 서버 기준 완료 시각, 정답 점수, 시간 가산점과 총점
- 오답 수와 입력 잠금 종료 시각
- 현재·다음 문제 이미지 로드 상태
- 연결 상태

한 플레이어가 문제를 완료해도 전체 상태는 `PLAYING`으로 유지되고 해당 플레이어의 문제 인덱스만 증가한다. 한 명이 준비된 전체 문제를 먼저 완료하면 해당 플레이어의 승리로 즉시 `FINISHED`로 전환한다.

## 4. 마감과 결과

- `READY` 30초 시간초과와 `PRELOADING` 실패·시간초과는 `CANCELLED`다.
- `COUNTDOWN`은 서버 시작 시각에 `PLAYING`으로 전환한다.
- 전체 문제를 먼저 완료한 플레이어가 즉시 승리한다. `PLAYING` 시간 마감에는 총점, 오답, 완료 시각 순서로 승패를 판정한다.
- 직접 이탈 또는 재접속 유예 초과는 상대 기권승이다.
- 서버가 상태를 신뢰할 수 없으면 `CANCELLED`다.

## 5. 공개 범위

경기 중에는 자신의 현재 이미지 쌍·발견 위치·오답, 상대의 현재 문제 번호·현재 발견/실제 정답 수·전체 발견/실제 전체 정답 수와 공통 마감 시각을 공개한다. 미발견 정답, 상대가 찾은 정확한 좌표와 이후 문제의 정답은 비공개다. `FINISHED`에서 양쪽 최종 진행을 공개한다. 전체 정답 검토 화면은 후속 기능이다.

## 6. 동시성

- 서버가 경기 상태와 플레이어별 진행 버전을 관리한다.
- 선택은 현재 상태, `pairId`와 문제 인덱스가 맞아야 한다. 같은 `PLAYING` 상태의 동시 입력은 상대 진행으로 전역 버전이 바뀌어도 서버 도착 순서로 판정한다.
- 동일 정답 중복 요청은 한 번만 반영한다.
- 입력 잠금 중 요청과 마감 이후 요청은 거절한다.
- 재접속 시 서버 스냅샷으로 현재 문제와 진행을 복구한다.
- 종료 경기는 결과 화면을 닫기(`game:dismiss`) 전까지만 재접속 시 다시 표시한다. 닫은 뒤에는 로비로 연결한다.
- 스냅샷의 `serverNowMs`로 기기 시계 오차를 보정해 남은 시간·카운트다운·오답 잠금을 표시한다.
