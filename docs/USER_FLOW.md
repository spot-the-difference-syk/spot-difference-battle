# 사용자 흐름

> 문서 상태: CURRENT
> 기준일: 2026-10-02
> 규칙은 `GAME_RULES.md`를 따른다.

## 처음 접속

`접속 → 닉네임 정하기 → 홈(오늘의 전시)`

닉네임은 대결 상대에게 보인다. 접속하면 서버가 게스트 세션과 성장 정보(레벨·코인·꾸미기·수집·오늘의 목표)를 보낸다.

## 대결

`홈 → 모드 선택 → 대결하기 → 매칭 → 준비 → 그림 미리 불러오기 → 3초 카운트다운 → 반복 풀이 → 결과·보상 → 홈`

1. 같은 모드를 고른 사람과 매칭된다. 서버가 이번 경기 화풍 하나를 무작위로 정하고, 준비 화면에 "이번 대결 · 화풍 · 그림 수"를 보여준다.
2. 그 화풍 그림 최대 10점의 순서는 두 사람에게 같다.
3. 첫 그림과 다음 그림을 미리 불러오고, 양쪽 로드가 끝나면 그림을 가린 채 3초 카운트다운한다.
4. 수정본에서 다른 곳을 누른다. 정답이면 뷰파인더 표시가 남고, 이미 찾은 곳은 다시 눌러도 불이익이 없다.
5. 오답이면 오답 수가 늘고 1초 동안 입력이 잠긴다.
6. 3개를 모두 찾으면 상대를 기다리지 않고 다음 그림으로 넘어간다.
7. 이번 경기 그림을 먼저 모두 끝내면 바로 이긴다. 시간이 끝나면 서버가 점수·오답 순으로 판정한다.
8. 결과 화면에서 승패, 양쪽 진행, 받은 경험치·코인, 레벨업, 새로 수집한 그림, 오늘의 목표 달성을 확인한다.

상대 화면에는 진행 수치만 보이고 정확한 발견 위치는 보이지 않는다.

## 혼자하기

`홈 → 혼자하기 → 그림 선택 → 3초 카운트다운 → 5개 찾기 → 기록·보상`

오답마다 기록에 3초가 더해진다. 퍼즐별 최고 기록은 기기에 저장하고, 완주하면 서버가 보상(하루 5번까지)과 수집을 반영한다.

## 꾸미기·내 정보

- 꾸미기: 레벨로 풀리는 무료 아이템을 쓰거나, 코인으로 아이템을 사서 바로 착용한다.
- 내 정보: 레벨·코인·전적·오늘의 목표와 "내 갤러리"(수집한 그림)를 본다.

## 예외 흐름

- 매칭 취소: 홈 복귀, 기권 아님
- 이미지 로드 실패·준비 시간초과: 승패 없이 취소
- 직접 나가기: 상대 기권승(나간 사람은 보상 없음)
- 연결 끊김: 10초 복귀 유예 후 미복귀 시 상대 기권승
- 서버 판정 불가: 승패 없이 취소
- 그림 오류: 결과 화면에서 신고
