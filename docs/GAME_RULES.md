# 게임 규칙

> 문서 상태: CURRENT
>
> 기준일: 2026-09-04

역할, 행동 권한, 수치, 시간, 승패, 기권, 정보 공개와 신고 조건은 이 문서에서만 정의한다. 다른 문서는 이 규칙을 화면·상태·기술·테스트 관점으로 설명한다.

## 1. 게임 목표

두 플레이어가 동일한 원본과 변경본을 비교해 차이점을 빠르게 찾는다. 한 문제에 등록된 실제 차이점을 모두 찾으면 각자 즉시 다음 문제로 이동한다. 전체 문제를 먼저 완료한 플레이어의 승리로 즉시 종료한다.

- 두 플레이어 모두 `찾는 사람`이며 제작자 역할은 없다.
- 서버는 두 플레이어에게 같은 순서의 검증된 문제 세트를 제공한다.
- 문제 하나는 원본 이미지, 변경본 이미지와 하나 이상의 검수된 정답 영역으로 구성한다. 문제별 정답 수는 달라질 수 있다.
- 각 플레이어의 진행은 독립적이다. 먼저 현재 문제를 완료한 플레이어는 상대를 기다리지 않는다.
- 제한시간은 기본전 180초, 속도전 60초, 생존전 120초다.
- 준비 제한시간은 30초, 시작 카운트다운은 3초다.
- 경쟁전에는 힌트가 없다.
- 오답 잠금은 쉬움 0.5초, 보통 1초, 어려움 2초다. 생존전은 누적 오답 3회에 도달하면 패배한다.
- 연결이 끊기면 10초 동안 복귀를 기다린 뒤 기권 처리한다.

이 수치는 코드 전환 시 공유 `GAME_CONFIG`와 함께 확정한다. 문서와 코드가 다르면 출시 가능한 상태가 아니다.

## 2. 문제 세트

각 문제는 다음 조건을 모두 충족해야 한다.

- 고유한 `pairId`와 버전이 있다.
- 원본과 변경본은 같은 크기, 비율, 구도와 크롭을 사용한다.
- 의도한 차이점이 하나 이상이며 문제 데이터의 실제 정답 수와 일치한다.
- 정답 영역은 정규화 좌표로 사전 등록한다.
- 문제 이미지와 정답 영역의 해시 또는 버전을 추적할 수 있다.
- 라이선스, 원작자, 생성 도구와 이용 조건을 확인한다.
- 모바일에서 확대했을 때 각 차이를 독립적으로 식별할 수 있다.

생성형 편집으로 영역 밖 픽셀이 미세하게 달라질 수 있으므로 원본과 변경본의 전체 픽셀 차이를 자동 정답으로 사용하지 않는다. 제작자가 지정하고 검수한 영역만 정답이다.

같은 경기 안에서는 같은 문제를 반복하지 않는다. 두 플레이어는 같은 문제 순서를 받는다.

## 3. 준비와 시작

1. 두 플레이어가 매칭되고 준비한다.
2. 서버가 경기용 문제 순서와 버전을 확정한다.
3. 양쪽 클라이언트가 첫 문제와 다음 문제를 미리 불러온다.
4. 양쪽의 첫 문제 로드 완료를 서버가 확인한다.
5. 서버 기준 3초 카운트다운 후 동시에 경기를 시작한다.

로드 실패와 준비 시간초과는 승패가 아닌 `CANCELLED`로 처리한다. 카운트다운 전에는 문제 이미지를 가려 미리 찾을 수 없게 한다.

## 4. 차이점 찾기

- 플레이어는 변경본 이미지에서 답을 선택한다.
- 서버는 현재 `pairId`, 문제 버전과 정답 영역을 기준으로 판정한다.
- 처음 맞힌 정답만 발견 수에 추가한다.
- 이미 찾은 영역을 다시 선택해도 오답이나 잠금으로 처리하지 않는다.
- 정답이 아닌 선택은 오답 수를 1 올리고 선택한 난이도의 입력 잠금을 적용한다.
- 입력 잠금 중 요청, 마감 이후 요청, 현재와 다른 상태 요청과 서버보다 앞선 버전 요청은 반영하지 않는다. 같은 `PLAYING` 상태에서 상대 입력 때문에 버전이 바뀐 동시 요청은 서버 도착 순서로 판정한다.
- 플레이어가 현재 문제에 등록된 실제 정답을 모두 찾으면 해당 문제를 완료하고 즉시 다음 문제로 이동한다.
- 다음 문제 로딩 시간으로 손해를 보지 않도록 다음 이미지 쌍을 미리 불러온다.

상대에게는 현재 문제 번호, 현재 문제 발견 수/실제 정답 수, 전체 발견 수/실제 전체 정답 수를 보여준다. 상대가 찾은 정확한 위치와 다음 문제의 정답은 경기 종료 전 공개하지 않는다.

## 5. 점수와 승패

경기 중 표시하는 진행 정보:

- 현재 문제 번호와 완료 여부
- 현재 문제의 발견 수/실제 정답 수
- 전체 발견 수/경기 전체 실제 정답 수
- 오답 수

경기 전체 실제 정답 수는 경기 문제 목록에 등록된 정답 영역 수를 합산한다.

- 정답 발견 점수: 1개당 10점
- 완주 시간 가산점: 전체 문제 완료 시 남은 시간 1초당 0.5점
- 총점: 총 발견 수 × 10 + 완주 시 남은 초 × 0.5

시간 가산점은 서버가 기록한 플레이어별 전체 완료 시각을 기준으로 소수 첫째 자리까지 계산한다. 전체 문제를 완료하지 못한 플레이어에게는 시간 가산점을 주지 않는다.

전체 문제를 먼저 완료한 플레이어가 즉시 승리한다. 제한시간 종료 시 승패 우선순위는 다음과 같다.

1. 총점이 높은 플레이어
2. 총점이 같으면 오답이 적은 플레이어
3. 오답도 같으면 전체 문제를 먼저 완료한 플레이어
4. 모두 같으면 무승부

기권과 생존전 오답 한도 종료는 해당 규칙의 승패를 우선한다.

## 6. 시간과 공정성

- 경기 시작, 종료와 입력 잠금은 서버 시각으로 판정한다.
- 두 플레이어에게 같은 문제 순서와 버전을 제공한다.
- 이미지 로딩 완료 전에는 경기 시간을 시작하지 않는다.
- 서버가 먼저 승인한 유효 입력을 반영한다.
- 상대의 발견 위치는 비공개로 유지한다.
- 클라이언트가 보낸 점수나 정답 여부를 신뢰하지 않는다.
- 과도한 입력과 동일 위치 반복 입력을 제한한다.

## 7. 이탈과 오류

- 플레이어가 직접 나가면 상대가 기권승한다.
- 연결이 끊기면 10초 동안 복귀를 기다린다.
- 유예시간 안에 복귀하지 못하면 상대가 기권승한다.
- 짧은 재접속 중에도 서버 경기 시간은 계속 흐른다.
- 양쪽이 모두 이탈하거나 서버가 결과를 신뢰할 수 없으면 `CANCELLED`로 처리한다.

## 8. 결과와 공개

결과 화면에는 승패·무승부·취소, 종료 사유, 양쪽의 완료 상태·발견 수/실제 전체 정답 수, 총점, 정답 점수, 시간 가산점과 오답 수를 표시한다. 문제별 전체 정답 검토 화면은 후속 기능이다.

현재 결과 행동은 로비 이동과 문제 신고다. 재대전과 결과 화면 즉시 새 매칭은 후속 기능이다.

## 9. 솔로 타임어택

혼자 플레이를 선택하면 매칭이나 서버 경기 없이 솔로 전용 문제를 푼다.

- 경쟁전과 다른 신규 원본·변경본 이미지 세트 5개를 사용한다.
- 각 문제에는 검수된 차이점이 정확히 5개 있다.
- 문제 이미지를 모두 불러온 뒤 3초 카운트다운하고 측정을 시작한다.
- 변경본에서 5개를 모두 찾을 때까지의 경과시간을 기록한다.
- 오답 1회마다 최종 기록에 3초를 추가한다.
- 힌트는 없으며 정답 판정 반경은 정규화 좌표 기준 최대 0.055인 어려운 난이도로 고정한다.
- 퍼즐별 최단 기록을 현재 기기의 로컬 저장소에 보존한다.
- 솔로 기록은 경쟁전 점수·전적·신고와 연결하지 않으며 서버 전체 순위로 사용하지 않는다.

## 10. 신고

완료되거나 취소된 경기에서 플레이어당 한 번 신고할 수 있다. 사유는 불공정, 이미지 문제, 부적절한 표현, 시스템 오류와 기타다. 신고는 저장만 하며 자동 제재하지 않는다.

운영 검토를 위해 경기의 문제 순서, `pairId`, 버전, 이미지 해시, 정답 영역과 플레이어 입력 결과를 보존해야 한다.

## 11. 레벨과 코인

보상은 항상 게임 서버가 계산하고 저장한다. 규칙 값의 정본은 `packages/shared/src/game/progression.ts`의 `PROGRESSION_RULES`다.

| 결과 | 경험치 | 코인 |
| --- | --- | --- |
| 대결 승리 | 100 | 120 |
| 대결 무승부 | 60 | 60 |
| 대결 패배 | 40 | 30 |
| 솔로 완주 | 30 | 20 |

- 레벨 1에서 2까지 경험치 100이 필요하고, 레벨마다 필요한 경험치가 20씩 늘어난다.
- 같은 경기 보상은 한 번만 지급한다. 취소된 경기와 기권패(직접 나가거나 재접속 유예 초과)는 보상하지 않는다.
- 솔로 보상은 한국 시간 하루 5번까지다. 3초보다 빠른 완주 기록은 비정상으로 보고 보상하지 않는다.
- 레벨·코인이 있는 게스트 세션은 마지막 접속 후 180일 동안 보존한다. 기기 로컬 저장소의 게스트 토큰을 잃으면 기록도 찾을 수 없으므로 계정 연동 전까지 기기 간 이전은 지원하지 않는다.
- Node 서버는 `player_growth` 테이블(마이그레이션 `20261001000100_player_growth.sql`)에, Cloudflare Worker는 Durable Object의 게스트 세션 기록에 저장한다.

## 12. 꾸미기

아이템 목록과 가격의 정본은 `packages/shared/src/game/cosmetics.ts`의 `COSMETIC_ITEMS`다. 구매·착용은 게임 서버가 레벨과 코인을 검증한 뒤 처리한다.

- 자리: 정답 표시, 액자, 프로필 테두리, 칭호. 정답 표시·액자는 내 화면에만, 프로필 테두리·칭호는 대결 상대에게도 보인다.
- 가격이 0인 아이템은 해금 레벨이 되면 바로 쓸 수 있다. 유료 아이템은 해금 레벨 이상에서 코인으로 사며, 사면 바로 착용한다.
- 산 아이템은 환불하지 않는다. 각 자리에는 무료 기본 아이템이 있다.
- 새 아이템을 추가하면 웹 `gallery.css`에 같은 ID의 스타일을 함께 만든다.
